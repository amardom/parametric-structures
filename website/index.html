Methodology

Finite element analyses are performed in Elmer, with custom elements using Fortran 2003 syntax.

Beams and hangers are modelled with 1D elements, slabs and walls with shells, and local details with 3D solids.

Structural optimisation is performed in Python using SciPy SLSQP, with constraints evaluated in Elmer.
